================================================================================
  КАК ПОДКЛЮЧИТЬСЯ К VPN (WireGuard)
  Инструкция для команды
================================================================================

Что вы получите от администратора
---------------------------------
  Один файл с расширением .conf (например: ivan.conf)
  Это ВАШ личный ключ — никому не пересылайте и не выкладывайте в чаты.

После подключения:
  • Весь интернет идёт через наш сервер (Нидерланды)
  • Внешний IP: 188.137.180.149
  • Нужен для доступа к сервисам (в т.ч. Gemini)


================================================================================
  WINDOWS 10 / 11
================================================================================

Шаг 1. Установить программу
  1. Откройте в браузере: https://www.wireguard.com/install/
  2. Нажмите «Windows» → скачайте установщик.
  3. Запустите установщик → Далее → Установить.
  4. После установки откроется окно WireGuard.

Шаг 2. Импортировать конфиг
  1. Внизу слева нажмите «Добавить туннель» (Add tunnel).
  2. Выберите «Импортировать туннели из файла».
  3. Укажите файл .conf, который вам прислали в Telegram
     (сохраните его на Рабочий стол или в «Загрузки»).
  4. Появится туннель с именем (например egrchik1).

Шаг 3. Подключиться
  1. Выберите туннель в списке слева.
  2. Нажмите «Подключить» (Activate).
  3. Статус должен стать: «Подключен» (зелёный).

Шаг 4. Проверка
  1. Откройте https://ifconfig.me
  2. Должен отображаться IP: 188.137.180.149
  Если другой IP — VPN не включён или импортирован не тот файл.

Отключение
  • В WireGuard нажмите «Отключить» — интернет снова пойдёт напрямую.


================================================================================
  ANDROID (телефон)
================================================================================

Шаг 1. Установить приложение
  1. Google Play → поиск «WireGuard».
  2. Установите официальное приложение (иконка туннеля, разработчик WireGuard).

Шаг 2. Импортировать конфиг
  Вариант А — файл из Telegram:
    1. Скачайте .conf файл в Telegram (нажмите на файл → Сохранить).
    2. Откройте WireGuard → «+» внизу справа.
    3. «Импорт из файла» / «Import from file».
    4. Выберите скачанный файл (часто в папке Download / Загрузки).

  Вариант Б — QR-код (если админ пришлёт QR):
    1. WireGuard → «+» → «Сканировать QR-код».
    2. Наведите камеру на QR.

Шаг 3. Подключиться
  1. Переключатель напротив туннеля — в положение ВКЛ.
  2. Android спросит разрешение на VPN — нажмите «ОК» / «Разрешить».

Шаг 4. Проверка
  • Браузер → https://ifconfig.me → IP 188.137.180.149

Отключение
  • Выключите переключатель туннеля в WireGuard.


================================================================================
  iPhone / iPad (iOS)
================================================================================

Шаг 1. Установить
  1. App Store → поиск «WireGuard» → Установить.

Шаг 2. Импорт
  1. Откройте файл .conf в «Файлы» или из Telegram
     (Поделиться → WireGuard).
  2. Или: WireGuard → «+» → «Создать из файла или архива».
  3. Выберите .conf.

Шаг 3. Подключение
  1. Включите переключатель туннеля.
  2. Подтвердите «Разрешить добавление конфигураций VPN».

Шаг 4. Проверка
  • Safari → https://ifconfig.me → 188.137.180.149


================================================================================
  macOS
================================================================================

  1. https://www.wireguard.com/install/ → macOS → установить из App Store
     или .dmg с сайта.
  2. WireGuard → «Import tunnel(s) from file» → выбрать .conf.
  3. Activate → проверить ifconfig.me.


================================================================================
  ЧАСТЫЕ ПРОБЛЕМЫ
================================================================================

«Подключен», но сайты не открываются / нет DNS
  • Отключите VPN и подключите снова.
  • Убедитесь, что в конфиге одна строка DNS = 1.1.1.1
    (если старый файл — попросите новый у администратора).
  • Перезагрузите телефон / ПК.

Интернет пропал полностью при включении VPN
  • Сразу отключите туннель в WireGuard.
  • Напишите администратору — пришлёт обновлённый .conf.

Не подключается / нет handshake
  • Проверьте Wi‑Fi или мобильный интернет без VPN.
  • Отключите другой VPN, если установлен.
  • Попробуйте другую сеть (раздача с телефона).
  • Напишите администратору.

Несколько устройств
  • Один .conf = одно устройство одновременно.
  • Для второго телефона/ПК попросите отдельный доступ у админа.

Потеряли файл .conf
  • Напишите администратору в личку — вышлет снова.
  • Не просите чужой файл — не будет работать.


================================================================================
  БЕЗОПАСНОСТЬ
================================================================================

  ✓ Храните .conf только у себя.
  ✓ Не отправляйте конфиг в общие чаты.
  ✓ При увольнении / потере телефона — сообщите администратору.

  ✗ Не публикуйте скриншоты конфига (там секретный ключ).

  2. Импортировать присланный файл .conf.
  3. Включить туннель → проверить https://ifconfig.me (IP 188.137.180.149).

По вопросам — пишите администратору VPN в личные сообщения.
